# 국어 수업 라이브 슬라이드 에디터

국어 수업용 라이브 슬라이드 에디터(reveal.js + summernote)의 **화면(프런트엔드)** 코드입니다.

- 실제 앱은 Google Apps Script 웹앱으로 동작하며, GAS가 이 저장소의 `Index.html`을 실시간으로 불러와 화면으로 보여줍니다.
- 데이터(작품별 슬라이드)는 각 사용자 **본인의 구글 드라이브** 폴더(`국어수업슬라이드`)에 작품마다 JSON 파일로 저장됩니다. 이 저장소에는 개인 데이터가 없습니다.
- `Index.html`을 수정해 커밋하면, 웹앱을 새로고침했을 때 자동으로 반영됩니다(별도 재배포 불필요).
